# Spark One 官方申请与表单申报中心 (SparkForm)

这是一个 100% 独立运行的标准化表单申报与管理平台，专为 A4 精准打印、矢量 PDF 导出与 Word (.docx) 下载打造。

## ✨ 核心特性

- 🌐 **12 种国际语言无缝切换**：简体中文、繁體中文、English、한국어、日本語、ไทย、Tiếng Việt、Bahasa Indonesia、Bahasa Melayu、Español、Português、العربية（支持 RTL 布局）。
- 📄 **四大官方标准申报表单**：
  1. **FORM-01 市场领航扶持账号申请**（极致单页排版）
  2. **FORM-02 办公室补贴申请表**（严格 A4 双页标准排版 01/02 & 02/02）
  3. **FORM-03 讲师补贴申请表**（严格 A4 双页标准排版 01/02 & 02/02）
  4. **FORM-04 活动申请表**（A4 单页经典排版）
- ✍️ **纯本地 Canvas 电子签名板**：支持手写签名、清除与导出。
- 📑 **一键导出 Word 文档 (.docx)**：客户端本地直接排版生成结构化 Word 文件。
- 🖨️ **一键导出标准 A4 PDF**：自适应物理 A4 比例，无空白多余页。
- 🚀 **零后端纯静态架构**：无需服务器与数据库，可直接部署在任意静态托管平台（GitHub Pages、Vercel、Cloudflare Pages、Netlify 等）。

## 🛠️ 本地运行

```bash
# 安装依赖
npm install

# 启动本地服务
npm run dev
```

启动后访问 `http://localhost:3000/` 即可直接使用。
